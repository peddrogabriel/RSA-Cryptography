Como funciona?

O RSA utiliza um par de chaves: uma pública, usada para criptografar, e outra privada, usada para descriptografar.

Informe dois números primos distintos e um expoente público válido.

ALGORITMO RSA

Segurança baseada na matemática

O RSA é um algoritmo de criptografia assimétrica. Ele utiliza duas chaves relacionadas matematicamente: a chave pública e a chave privada.
